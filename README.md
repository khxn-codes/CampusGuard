# CampusGuard 🛡️

An AI-assisted campus security monitoring system. Uses OpenCV for real-time motion detection, restricted-zone and time-based rule checking, and a Streamlit dashboard for viewing and reviewing alerts.

## Features

- Live camera feed with motion detection (frame differencing + contours)
- Restricted zone checking — flags movement inside a defined area
- Time-rule checking — flags activity outside allowed hours
- Alert severity classification (Low / Medium / High)
- Streamlit dashboard: live feed, alert filtering, alert review/resolution, analytics, campus map, activity feed

## Project Structure

```
CampusGuard/
├── app.py                 # Entry point — Streamlit dashboard + live feed
├── config.py               # Shared settings: zone coords, allowed hours, cooldown, log path
├── logger.py                # EventLogger — writes alerts to logs/alerts_log.csv
├── test_run.py               # Standalone sanity check for logger.py
├── backend/
│   ├── __init__.py
│   ├── camera.py           # Webcam capture
│   ├── detector.py          # Motion detection (preprocessing, frame diff, contours)
│   ├── zones.py              # Restricted zone checking (reads zone from config.py)
│   └── alerts.py              # Severity + time-rule alert logic (reads hours/cooldown from config.py)
├── logs/
│   └── alerts_log.csv      # Alert log (created automatically)
├── requirements.txt
└── .gitignore
```

## Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/khxn-codes/CampusGuard.git
   cd CampusGuard
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS/Linux
   source .venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the App

```bash
streamlit run app.py
```

This opens the dashboard in your browser (usually `localhost:8501`). Go to the **Live Feed** page and check "Start camera" to run the full detection pipeline.

**Important:** run this command from the project root (`CampusGuard/`), not from inside `backend/`. `config.py` sits at the root, and `zones.py`/`alerts.py`/`logger.py` import it as `from config import ...` — running from the wrong folder causes `ModuleNotFoundError: No module named 'config'`.

## Configuration

All tunable settings live in `config.py`:

| Setting | Used by | Meaning |
|---|---|---|
| `CAMERA_INDEX` | — | Which camera to open (0 = default webcam) |
| `RESTRICTED_ZONE` | `backend/zones.py` | Zone coordinates in pixels: `(x1, y1, x2, y2)` |
| `ALLOWED_START_HOUR` / `ALLOWED_END_HOUR` | `backend/alerts.py` | Normal hours (24h format); outside this window counts as after-hours |
| `ALERT_COOLDOWN` | `backend/alerts.py` | Minimum seconds between two logged alerts |
| `LOG_FILE_PATH` | `logger.py` | Where `EventLogger` writes the CSV |

Change a value here and it takes effect everywhere that imports it — no need to edit `zones.py`, `alerts.py`, or `logger.py` directly.

## Alert Data Format

Each alert generated by the backend follows this schema:

| Field | Description |
|---|---|
| `date` | Date of the event (DD-MM-YYYY) |
| `time` | Time of the event (HH:MM:SS) |
| `location` | Camera/location identifier |
| `event_type` | Description of what was detected |
| `severity` | Low / Medium / High |
| `status` | Unreviewed / Under Review / Resolved |

Alerts are written to `logs/alerts_log.csv` by `logger.py`'s `EventLogger` class, and read by the dashboard for the Dashboard, Alerts, and Analytics pages.

## Known Issues

- `requirements.txt` was saved with UTF-16 encoding (common when generated via `pip freeze` in Windows PowerShell). If `pip install -r requirements.txt` fails or behaves oddly on a fresh clone, re-save the file as UTF-8.
- `RESTRICTED_ZONE` in `config.py` is set to fixed pixel coordinates — recalibrate it to match your actual demo camera's framing before presenting.
