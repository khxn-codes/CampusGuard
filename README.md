# CampusGuard 🛡️

An AI-assisted campus security monitoring system. Uses OpenCV for real-time motion detection, restricted-zone and time-based rule checking, and a Streamlit dashboard for viewing and reviewing alerts.

## Features

- Live camera feed with motion detection (frame differencing + contours)
- Restricted zone checking — flags movement inside a defined area
- Time-rule checking — flags activity outside allowed hours
- Alert severity classification (Low / Medium / High)
- Streamlit dashboard: live feed, alert filtering, alert review/resolution, analytics, campus map, activity feed

## Project Structure

```
CampusGuard/
├── app.py                 # Entry point — Streamlit dashboard + live feed
├── backend/
│   ├── __init__.py
│   ├── camera.py           # Webcam capture
│   ├── detector.py          # Motion detection (preprocessing, frame diff, contours)
│   ├── zones.py              # Restricted zone checking
│   └── alerts.py              # Severity + time-rule alert logic
├── logger.py               # Writes alerts to logs/alerts_log.csv
├── config.py               # Shared settings (zone coords, allowed hours, thresholds)
├── logs/
│   └── alerts_log.csv      # Alert log (created automatically)
├── data/                   # Stored event data
├── requirements.txt
└── .gitignore
```

## Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/khxn-codes/CampusGuard.git
   cd CampusGuard
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS/Linux
   source .venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the App

```bash
streamlit run app.py
```

This opens the dashboard in your browser (usually `localhost:8501`). Go to the **Live Feed** page and check "Start camera" to run the full detection pipeline.

## Alert Data Format

Each alert generated by the backend follows this schema:

| Field | Description |
|---|---|
| `date` | Date of the event (DD-MM-YYYY) |
| `time` | Time of the event (HH:MM:SS) |
| `location` | Camera/location identifier |
| `event_type` | Description of what was detected |
| `severity` | Low / Medium / High |
| `status` | Unreviewed / Under Review / Resolved |

Alerts are written to `logs/alerts_log.csv` by `logger.py`, and read by the dashboard for the Dashboard, Alerts, and Analytics pages.
